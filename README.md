# Portfolio di Umberto

Sito statico con ritratto di particelle animato. Nessuna build: apri `index.html` da un server locale.

```bash
python3 -m http.server 8765
```

Poi vai su `http://localhost:8765/`. Contenuti e lingue si modificano in cima allo script di `index.html`. Dettagli in `CLAUDE.md` e `HANDOFF.md`.
